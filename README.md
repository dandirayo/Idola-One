# Idola One Web

Aplikasi web operasional dan kasir multi-usaha untuk Idola Laundry. Menggantikan aplikasi Android Flutter dan dashboard owner dari repo `LaundryApp`, dengan tetap memakai database Supabase yang sama.

Status: tahap perencanaan. Kode belum dibuat.
